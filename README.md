# AVIA

Большое и сложное приложение для оценки авиационной транспортной сети РФ. Проект написан в рамках выпускной квалификационной работы специалиста в Московском Авиационном Институте.

---

Приложение написано на Qt, в нем используется муравьиный алгоритм, и много попыток в архитектуру на плюсах.
